## 本轮发现并修复

1. **Windows 中文文件删除导致进程原生崩溃。** Node 24.9 的 `fs.rmSync` 在本机最小复现退出 `0xC0000409`，同路径 `unlinkSync` 正常。新增 Windows 删除实现，以 unlink/rmdir 处理文件和目录，不递归进入链接/junction。文件 API、AI delete_file、快照撤销同步使用；回归覆盖中文/emoji、嵌套目录、缺失文件和外部链接目标保护。
2. **终端历史回放丢失。** attach 内同步发送快照，调用方尚未注册 onData。改为微任务发送；用计算生成的输出标记验证，避免把命令自身回显误当成执行结果。
3. **移回项目根目录被拒绝。** Android 根目录用空字符串表示，服务端此前按必填非空字段拒绝。统一映射为 `.`，保留缺失字段和越界路径拒绝测试。
4. **WSL 空密码不能解析。** Android `IdeAccessDto.password` 改为可空，兼容服务端的 `password:null`。
5. **Windows 环境误报。** health 确认 win32 后使用 PowerShell 读取本机信息；不再运行 Linux 探测命令，也不显示不适用的 tmux/systemd/Linger 行。
