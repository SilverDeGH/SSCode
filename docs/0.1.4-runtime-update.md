# 0.1.4 发布说明

保留此前紧凑 UI、复制对话、SSH 网页预览、后台任务恢复和折叠工作过程。

## 全接管修复

- 切换审批模式立即同步当前对话内的活动任务，并保存后续任务默认选择。
- 新增 POST /v1/tasks/:id/approval-mode，服务端先保存模式，再自动批准已有待审批操作。后续每个工具读取任务模式，全接管跳过全部工具审批和工具拒绝规则。
- 已完成任务不可修改模式；无效模式返回校验错误。全接管不会重启已停止任务，也不会消除模型错误、命令失败或执行轮次上限。
- 旧服务没有新接口时，客户端对明确选择自动审批/全接管的任务每秒自动批准待审批。此兼容行为需要工作区保持在线，不能解除旧服务的硬性拒绝规则。
- 完整离线全接管需要更新 APK 内置的配套服务。重新部署会检查活动任务，避免中途重启导致任务中断。

## 产物与验证

版本名 0.1.4，Android versionCode 10，可覆盖安装此前测试版本。
服务端类型检查通过；116 项测试中 114 项通过、2 项 Linux 专用测试在 Windows 跳过。
新增回归覆盖：等待审批时切换全接管、批准已有操作、无需客户端继续后续删除及敏感文件工具、最终完成并持久保存模式。
