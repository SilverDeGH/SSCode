### 1.2 范围分类

| 分类 | 含义 | 处理原则 |
|---|---|---|
| **已确认** | 需求文档明确写定的第一版范围 | 必须实现，进入验收 |
| **建议默认** | 需求文档标注"建议默认"的实现细节 | 按此实现，可在验证后调整并记录 |
| **验证项** | 需求文档标注"开发验证项"或依赖实测才能定案 | P1/P6 实测后定案，不提前承诺 |
| **范围排除** | 需求第 15 节明确不做 | 不实现，防止范围蔓延 |

### 1.3 验收映射

"验收"列对应《需求汇总.md》第 14 节 17 项验收标准编号（记作 AC-1 … AC-17）。

## 15. 关键异常场景映射（需求第 13 节）

| 异常场景 | 预期行为 | 关联需求 | 验证阶段 |
|---|---|---|---|
| SSH 密码或私钥错误 | 明确区分认证失败与网络失败 | REQ-CONN-02、REQ-UI-05 | P1、P3 |
| 主机指纹变化 | 阻止静默连接，要求核验 | REQ-CONN-09 | P3、P6 |
| 环境不兼容 | SSH 可继续使用，说明完整工作区不可用原因 | REQ-ENV-02、03 | P3 |
| 安装中断 | 保留阶段记录，允许检查后重试 | REQ-ENV-05 | P3、P6 |
| 模型 Key 无效或额度不足 | 任务受阻，提示修正配置 | REQ-AI-22 | P4、P6 |
| 模型不支持所需工具调用 | 不宣称可执行完整 AI 编程任务 | REQ-AI-06 | P1、P4 |
| 手机离线 | 服务器继续执行，审批步骤等待 | REQ-PERM-08、REQ-OPS-03 | P1、P4、P6 |
| 服务器重启 | 恢复记录，中断任务等待确认 | REQ-ENV-10、11 | P4、P6 |
| 磁盘不足或无法保存快照 | 暂停相关写入，不虚假承诺可撤销 | REQ-OPS-11、REQ-UNDO-07 | P4、P6 |
| 人工与 AI 修改冲突 | 提示冲突，不静默覆盖 | REQ-UNDO-06 | P4、P6 |
| Git 冲突 | 保留状态，引导完整 IDE | REQ-GIT-03 | P5、P6 |
| 命令无法立即停止 | 如实显示状态，不提前报告已完全停止 | REQ-AI-18 | P4、P6 |
