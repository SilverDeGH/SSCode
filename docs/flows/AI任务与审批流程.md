## 1. 任务生命周期主流程

```mermaid
flowchart TD
    A[AI 首页输入需求<br/>可引用文件/代码/终端错误] --> B{当前项目有执行中任务?}
    B -->|无| C[发送 = 新任务]
    B -->|有| C1[发送 = 追加当前任务要求<br/>文案明确区分]
    B -->|已有排队| C2[发送 = 排队任务<br/>展示队列位置]
    C & C1 & C2 --> D[手机生成客户端请求标识<br/>发送至服务器]
    D --> E{服务器接收确认?}
    E -->|未确认断线| E1[本地标记 发送状态未知<br/>重连后核对，不自动重复提交]
    E -->|确认| F{重复请求标识?}
    F -->|重复| F1[返回原任务，不重复创建]
    F -->|新| G[写入任务记录<br/>同项目串行排队/立即执行]

    G --> H[任务执行循环]
    H --> H1[权限判断：统一前置入口<br/>检查实际操作与上下文]
    H1 -->|自动执行类| H2[执行：读取/修改/命令/测试<br/>修改前写快照]
    H1 -->|需审批类| H3[生成审批卡片<br/>操作+参数/目标/原因/影响]
    H3 --> I{用户选择}
    I -->|批准本次| H2
    I -->|拒绝并补充要求| H4[记录拒绝与补充<br/>AI 调整后续步骤]
    I -->|停止任务| S[停止流程]
    I -->|手机离线| I1[等待确认，不自动放行<br/>任务挂起在等待审批]
    H2 --> H5{收到追加要求?}
    H5 -->|是| H6[标记 已收到/已纳入后续执行<br/>在安全步骤处理]
    H5 -->|否| H7{任务完成?}
    H6 --> H7
    H7 -->|否，继续循环| H
    H7 -->|是| J[任务总结：做了什么/修改文件/<br/>验证结果/限制与待办]
    J --> K[变更文件列表与差异审查入口]
```

## 2. 停止流程

```mermaid
flowchart TD
    A[用户点击 停止任务] --> B[状态：正在停止]
    B --> C[阻止发起新的工具调用]
    C --> D[尝试终止该任务运行中的子进程]
    D --> E{全部终止?}
    E -->|是| F[状态：已停止]
    E -->|部分无法终止| G[如实显示：哪些进程仍在运行<br/>不提前报告已完全停止]
    F & G --> H[保留已发生修改与执行记录]
    H --> I[提供 修改审查 与 单独撤销入口<br/>停止 ≠ 外部影响已撤销]
```

## 3. 断线与恢复流程

```mermaid
flowchart TD
    A[手机断线/切后台/被杀] --> B[服务器任务继续运行<br/>事件持续写入持久化存储]
    B --> C[手机界面显示断线状态<br/>原因 + 重连入口 + 说明文案]
    C --> D[用户重连]
    D --> E[重建 SSH 隧道]
    E --> F[以事件游标拉取缺失事件]
    F --> G[恢复任务实时状态<br/>不使用断线前缓存状态冒充实时]
    G --> H{有待确认审批?}
    H -->|有| I[审批卡片置顶展示]
    H -->|无| J[正常展示]
```

## 4. 撤销流程

```mermaid
flowchart TD
    A[修改审查页 → 撤销任务修改] --> B{任务执行中?}
    B -->|是| B1[禁止撤销，提示先停止任务]
    B -->|否| C[撤销预览：将恢复的文件清单<br/>及无法恢复的项明确标注]
    C --> D{冲突检测}
    D -->|任务前已有改动| E[保护：恢复至任务前快照<br/>不触碰更早状态]
    D -->|后续人工修改/后续任务变更| F[冲突提示：不覆盖<br/>列出冲突文件由用户处理]
    D -->|无冲突| G[二次确认]
    E & F --> G
    G -->|确认| H[按快照恢复并记录撤销操作]
    G -->|取消| I[返回]
    H --> J[结果反馈：已恢复/被跳过及原因<br/>数据库/已推送/外部写入不在撤销范围]
```

## 5. 关键设计要点

1. **去重三原则**：客户端请求标识去重（任务提交）、审批与具体操作绑定（操作变更需重新申请）、断线指令"发送状态未知"不自动重发（REQ-OPS-01、REQ-PERM-09、REQ-UI-15，对应 AC-17）。
2. **权限判断前置统一入口**：任何工具执行前过权限规则，凭实际操作与上下文判断，不凭命令名放行，也不单凭模型自我声明（REQ-PERM-02）。
3. **串行与并发**：同项目按规范化目录串行排队，跨项目并发；资源不足如实报告（REQ-PROJ-10—12）。
4. **快照先于修改**：修改类工具执行前必写快照；快照写失败（如磁盘不足）时暂停写入并明示"不可撤销"风险，不虚假承诺（REQ-UNDO-04、REQ-OPS-11）。
5. **手机离线安全语义**：任务继续、审批等待、不自动放行（REQ-PERM-08，对应 AC-8、AC-9）。
